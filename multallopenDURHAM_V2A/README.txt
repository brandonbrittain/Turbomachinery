The Durham Package of Multall-Open V2A

If you are doing the course at Durham these files are all you need.  

This is an extract from the "vanilla" download of MULTALLOPEN available at:

https://sites.google.com/site/multallopen/general-description

All taken from the 4/12/2020 Version 20.9 release.  

Changes from "vanilla" MULTALL OPEN:

Latest version of the FORTRAN sources extracted to single directory.  
PDF versions of the manuals and README extracted and renamed.  
stagen-18.1.f had lines 1512 to 1604 deleted to remove HGRAPH dependancy.  
We use the 20.6 version of the multall program as this has better compatability
with input files generated by other programs in the suite.  

meangen-14.4.f has lines 2449 adjusted to write more figures to avoid merging data
with high pressures and temperatures.  

Two directories: 
1) code - which contains the code
2) docs - which contains the documentation (should be repeated on duo)

Notes on how to use and compile the program for Durham use are found on
the online learning platform.
